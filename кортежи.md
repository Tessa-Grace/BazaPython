# Кортежи


Кортеж(tuple) - упорядоченная неизменяемая коллекция.


В отличие от строк, элементами кортежа **может быть всё** что угодно — просто надо перечислить через запятую в круглых скобках (при этом круглые скобки даже не всегда нужны).


**Кортежи поддерживают следующие операции** (почти как строки):

* подсчёт количества элементов с помощью len(),
* проверка вхождения элемента с помощью in,
* конкатенация,
* дублирование,
* превращение строки в кортеж букв с помощью tuple(),
* получение элемента по индексу,
* срезы.


**Методы кортежей:**

* .index(el) — индекс первого вхождения элемента в кортеж. Работает идентично одноимённому методу для строк (всё с теми же дополнительными параметрами).
* .count(el) — сколько раз элемент входит в кортеж.


\- Есть **перебор элементов кортежа** по индексу, по элементу (и с использованием enumerate()).

\- Есть **min()** и **max()**, но все элементы должны быть сравнимыми между собой. 

\- Есть **sum()**, если все элементы - числа.


**Сравнение:**

Как и строки, кортежи можно сравнивать. Причём кортежи сравниваются поэлементно: сначала сравниваются первые элементы, потом вторые, потом третьи и тд.

Важно, чтобы элементы, которые стоят на одинаковых позициях в кортежах, были сравнимыми друг с другом, а иначе — ValueError.

Пример:
```
print((1, 2, 3) == (1, 2, 3))  # True.

print((1, 2, 3) < (1, 2, 4))   # True 3 < 4.

print((1, 2) < (1, 2, 0))      # True; во втором кортеже есть ещё элементы, а в первом закончились.
```



###### **Примеры кортежей:**
```
\# Кортеж из трёх элементов; тип элементов может быть любой.

random\_info = 42, "Python", True  # Тут скобки не обязательны.

\# Но можно и указать.

card = ('7', 'пик')           

\# Никто не запретит положить кортеж в кортеж и т. д.

treasure = ("Клад", coords)

&nbsp; 

\# Пустой кортеж (из 0 элементов).

empty = ()  # скобки обязательны, иначе интерпретатор не догадается

&nbsp;

\# Кортеж из одного элемента — запятая нужна, чтобы отличить от обычных скобок.

t = (18,)  # Можно без скобок, но без запятой — никак.

tuple\_str = (

&nbsp;   "так",

&nbsp;   "тоже",

&nbsp;   "можно",

&nbsp;   "задавать",

&nbsp;   "кортеж"

)  # Скобки обязательны.
```
