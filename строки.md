# **Строки**

Строка — это неизменяемая упорядоченная коллекция строк единичной длины.


**Срезы:**

* line\[idx] — получить один элемент (букву) с индексом idx (это мы уже знаем).
* line\[start:stop] — получить все элементы с позиции start до позиции stop не включительно, т. е. строку, содержащую все буквы исходной, расположенные по этим индексам.
* line\[start:stop:step] — получить все элементы с позиции start до позиции stop не включительно с шагом step. Шаг, как и в range(), может быть отрицательным, тогда индекс начала должен быть больше индекса конца.
* line\[:stop] — если не указано начало, то от начала до нужного индекса не включительно.
* line\[start:] — не указан конец — до конца строки/коллекции.
* line\[:] — строка от начала до конца (полная копия — для строк не особо полезно, но пригодится для другой коллекции).
* line\[::step] — от начала до конца с шагом.
* line\[::-1] — буквы строки / элементы коллекции в обратном порядке.


**Методы строк:**

* .find(substr) — найти первую позицию первого вхождения подстроки substr. Возвращает целое число: индекс элемента, с которого начинается вхождение, или −1 — если ничего не нашёл.
* .rfind(substr) — найти первую позицию последнего вхождения подстроки в строку. Возвращает целое число: индекс элемента, с которого начинается вхождение, или −1 — если ничего не нашёл.
* .index(substr) — как find(), но обидится, если не найдёт, — будет ошибка ValueError. Вообще, полный синтаксис метода чуть сложнее — .index(substr, start, stop) — ищет первое вхождение подстроки, начиная с индекса start и до индекса stop. Но в большинстве случаев используется только с одним аргументом — с тем, вхождение которого мы ищем.
* .count(substr) — возвращает целое число: сколько раз подстрока нашлась в строке.
* .replace(old, new, count) — подменить слово old на new, чтобы никто не заметил. Можно передать count — сколько вхождений менять. Если ничего не передать, то заменятся все вхождения. Возвращает строку с изменениями.


**Методы изменения регистра:**

* .lower() — опустить все буквы вниз (в нижний регистр).
* .upper() — кричать КАПСОМ.
* .capitalize() — стать приличным человеком: только первая заглавная.
* .title() — сделать заглавной первую букву каждого слова.
* .swapcase() — устроить хаос: поменять регистр у всех букв.


**Методы проверки содержимого:**

* .isalnum() — состоит ли строка только из букв и цифр?
* .isalpha() — только из букв?
* .isdigit() — только из цифр?
* .islower() — все буквы маленькие?
* .isupper() — все буквы большие?
* .isspace() — только пробельные символы (пробелы, табуляции, переносы строк)?


**Методы обрезания и очистки:**

* .strip() — убери пробелы (или другие символы) с начала и конца.
* .lstrip() — только слева.
* .rstrip() — только справа.

Если в методы ничего не передать, то будут убираться пробельные символы.

Если передать строку, тогда из исходной строки будут удаляться символы до тех пор, пока не встретится первый, не входящий в подстроку.


**Методы проверки начала и конца строки:**

* .startswith(substring) — начинается с...
* .endswith(substring) — заканчивается на...
Возвращают True или False.


**Обход строки по позиции элементов:**

* важны только сами элементы коллекции — проходимся по элементам;
* важна скорее позиция элемента — range();
* нужно и то и то — enumerate().
