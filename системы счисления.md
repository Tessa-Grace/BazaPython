# Системы счисления


**Встроенные функции для перевода из десятичной с/с:**

* bin() - двоичная — для настоящих гиков и микроконтроллеров (как мы говорили на первом уроке, это родной язык процессоров).
* oct() - восьмеричная — если вы заблудились в старых UNIX-мануалах.
* hex() - шестнадцатеричная — когда хочешь выглядеть умным и работаешь с цветами или адресами в памяти.
* десятичная — для нормальных людей. Так числа в Python выглядят по умолчанию.


**Для перевода в 10 с/с:**

* int(), где в качестве второго параметра указать основание системы счисления: a1 = int('0b1010', 2)  # 10. Поддерживает любые с/с от 2 до 36 (цифры + все английские буквы).


**Функции для перевода:**

* до 10 с/с:
```
def convert(num, sys):
```

```
from string import digits, ascii\_uppercase


alph = digits + ascii\_uppercase


def convert(num, sys):

&nbsp;   res = ''

&nbsp;   while num:

```
