# Списки


Список — это упорядоченная изменяемая коллекция.


**Создание:**
* непосредственно из кода, путем использования скобок \[]:
```
random\_things = \[1, False, (55, 44)]
```
* путём преобразования из других коллекций с помощью функции list():
```
chars = list('hello')  # \['h', 'e', 'l', 'l', 'o']
numbers = list(range(5))  # \[0, 1, 2, 3, 4]
```


**Индексация:**
* каждый элемент списка имеет индекс.
* срезы также прекрасно себя чувствуют и применительно к спискам (nums\[:] - копия списка).
* списки можно дублировать с помощью умножения на число, а также складывать друг с другом с помощью операции сложения — конкатенации.


**Методы списков:**
* .index(el) — индекс первого вхождения элемента в список.
* .count(el) — сколько раз элемент входит в список.


**Применимые функции:**
* max() и min(), но все элементы должны быть сравнимы между собой.
* sum() - если элементы - числа.


**Обход элементов списка с помощью цикла for:**
* по элементам;
* по индексам;
* по индексам и элементам с помощью enumerate().
